# **ГЛАВА 3: ОСНОВНИ ТЕОРЕМИ - НАЙ-ВАЖНОТО ЗА ИЗПИТ**

## **🎯 ЦЕЛ НА ГЛАВАТА:**
Доказваме, че **задачата на Коши е "коректно поставена"**, т.е.:
1. **Съществува** решение
2. **Единствено** е решението
3. **Зависи непрекъснато** от началните данни

---

## **§3.1 ТЕОРЕМА ЗА СЪЩЕСТВУВАНЕ И ЕДИНСТВЕНОСТ. МЕТОД НА ПОСЛЕДОВАТЕЛНИ ПРИБЛИЖЕНИЯ**

### **3.1.1 Задача на Коши**
Дадено:
```
x' = v(t, x),  (t, x) ∈ W ⊂ ℝ²
x(t₀) = x₀,   (t₀, x₀) ∈ W
```

### **3.1.2 Условие на Липшиц**
**Дефиниция:** Функцията f: U → ℝ е **Липшицова**, ако:
```
∃ L > 0: |f(x) - f(y)| ≤ L|x - y|  за всички x, y ∈ U
```
L се нарича **константа на Липшиц**.

**Важно:** Всяка **непрекъснато диференцируема** функция в компактен интервал е Липшицова:
```
L = sup|f'(x)| в интервала
```

### **3.1.3 Теорема (Пикар-Линделеф)**
**Условия:**
1. v(t,x) е **непрекъсната** в правоъгълника Π = {|t-t₀|≤a, |x-x₀|≤b}
2. v(t,x) е **Липшицова по x**: |v(t,x) - v(t,y)| ≤ L|x-y|

**Твърдение:** Съществува **единствено** решение x(t) на задачата на Коши, дефинирано в интервала |t-t₀| ≤ h, където:
```
h = min(a, b/M),  M = max|v(t,x)| в Π
```

---

## **ДОКАЗАТЕЛСТВО (МЕТОД НА ПИКАР)**

### **Стъпка 1: Преобразуване до интегрално уравнение**
Задачата на Коши е **еквивалентна** на:
```
            t
x(t) = x₀ + ∫ v(s, x(s)) ds
           t₀
```
(Лесно се проверява: диференцираме и получаваме първоначалното ДУ)

### **Стъпка 2: Построяване на последователни приближения**
**Нулево приближение:** x₀(t) ≡ x₀ (константа)

**Рекурентна формула:**
```
            t
x_{n+1}(t) = x₀ + ∫ v(s, x_n(s)) ds
           t₀
```

### **Стъпка 3: Доказваме, че приближенията са добре дефинирани**
Индукция: |x_n(t) - x₀| ≤ b (остават в правоъгълника Π)
```
|x₁(t)-x₀| = |∫v(s,x₀)ds| ≤ M|t-t₀| ≤ Mh ≤ b
```

### **Стъпка 4: Доказваме равномерна сходимост**
Полагаме:
```
y₀(t) = x₀(t)
y_n(t) = x_n(t) - x_{n-1}(t), n ≥ 1
```
С помощта на условието на Липшиц доказваме оценката:
```
|y_n(t)| ≤ M * L^{n-1} * |t-t₀|^n / n!
```
Тъй като редът ∑ y_n(t) се доминира от сходящия ред ∑ (M/L)*(Lh)^n/n!, по критерия на Вайерщрас редицата {x_n(t)} е **равномерно сходяща**.

### **Стъпка 5: Границата е решение**
Ако x(t) = lim x_n(t), то:
```
           t                    t
x(t) = lim ∫ v(s, x_n(s)) ds = ∫ v(s, x(s)) ds
       n→∞ t₀                  t₀
```

### **Стъпка 6: Единственост**
Да допуснем, че има две решения x(t) и z(t). Полагаме Q = max|x(t)-z(t)| в [β, β+η]. Тогава:
```
Q = |x(t₁)-z(t₁)| ≤ ∫|v(s,x)-v(s,z)|ds ≤ L∫|x-z|ds ≤ ηLQ
```
Ако изберем η < 1/L, получаваме Q < Q - **противоречие**! Значи решенията съвпадат.

## **§3.2 АПРОКСИМАЦИЯ НА РЕШЕНИЯТА. МЕТОД НА ОЙЛЕР**

### **Идея:** Заменяме интегралната крива с нейната **допирателна** в малки интервали.

### **Алгоритъм:**
1. Разделяме интервала [α, β] на N части с дължина h = (β-α)/N
2. t_k = t₀ + k*h
3. **Рекурентна формула:**
```
x_{k+1} = x_k + h * v(t_k, x_k), k = 0,1,...,N-1
```
4. Линейна интерполация между точките (t_k, x_k)

### **Грешка:** Локалната грешка е от порядък O(h²), глобалната - O(h).

---

## **§3.3 НЕПРЕКЪСНАТА ЗАВИСИМОСТ НА РЕШЕНИЕТО**

### **3.3.1 Неравенство на Гронуол**
Ако u(t), v(t) ≥ 0 са непрекъснати и:
```
              t
u(t) ≤ C + ∫ u(s)v(s) ds
             a
```
то:
```
              t
u(t) ≤ C * exp(∫ v(s) ds)
             a
```

### **3.3.2 Теорема за непрекъсната зависимост от начални данни**
Нека v(t,x) е Липшицова с константа L. Тогава за всякакви две решения x(t) и y(t) с начални условия x(t₀)=x₀, y(t₀)=y₀, е изпълнено:
```
|x(t) - y(t)| ≤ |x₀ - y₀| * e^{L|t-t₀|}
```

**Следствие:** Малка промяна в началните условия води до малка промяна в решението.

### **3.3.3 Непрекъсната зависимост от параметри**
Ако системата зависи от параметър μ:
```
x' = v(t, x, μ)
```
то решението е непрекъсната функция на μ.

---

## **§3.4 ДИФЕРЕНЦИРУЕМОСТ НА РЕШЕНИЯТА**

### **Уравнения във вариации**
Нека x(t) = φ(t, x₀) е решението на:
```
x' = v(t, x), x(t₀) = x₀
```
Тогава **частните производни** y = ∂φ/∂x₀ удовлетворяват **линейната** система:
```
y' = v_x(t, φ(t,x₀)) * y
```
с начално условие y(t₀) = I (единичната матрица).

### **Теорема:** 
Ако v ∈ Cᵐ, то решението φ(t, x₀) е от клас Cᵐ по началните условия.

## **§3.5 ТЕОРЕМА ЗА НЕПРОДЪЛЖИМОСТ**

### **Дефиниция:** 
Решението се нарича **непродължимо**, ако не може да бъде продължено извън максималния интервал на съществуване.

### **Основна теорема:**
Ако решението на задачата на Коши **не може** да бъде продължено за всички t, то то или:
1. **Излиза от всеки компакт** на фазовата равнина
2. **Има асимптота** при t → T (T е крайната точка на интервала)

### **Примери:**
1. **x' = x²**, x(0) = x₀ > 0: Решение x(t) = x₀/(1 - x₀t) → ∞ при t → 1/x₀
2. **Линейни системи:** x' = A(t)x - винаги продължими

### **Критерий за продължимост:**
Ако |v(t,x)| ≤ a + b|x| за всички (t,x), то всяко решение може да се **продължи** за всички t.

## **🔑 КЛЮЧОВИ ПОНЯТИЯ ЗА ИЗПИТ:**

### **1. Теорема на Пикар-Линделеф (най-важна!):**
```
Условия: 
1. v(t,x) непрекъсната
2. v(t,x) Липшицова по x

Резултат:
1. Съществува единствено решение
2. В интервал |t-t₀| ≤ h = min(a, b/M)
```

### **2. Метод на последователните приближения:**
```
x₀(t) = x₀
            t
x_{n+1}(t) = x₀ + ∫ v(s, x_n(s)) ds
           t₀
```

### **3. Условие на Липшиц:**
```
|f(x) - f(y)| ≤ L|x-y|
```
- Достатъчно условие: f ∈ C¹ в компакт → f е Липшицова
- L = max|f'(x)|

### **4. Непрекъсната зависимост:**
```
|x(t) - y(t)| ≤ |x₀ - y₀| * e^{L|t-t₀|}
```
- Малки начални грешки водят до малки грешки в решението

### **5. Теорема за непродължимост:**
- Решение се прекратява само ако "избяга в безкрайност" или достигне асимптота

### **6. Практически съвети:**
- Винаги **проверявай условието на Липшиц**
- За линейни системи решението винаги е продължимо
- Метод на Ойлер дава **приближено** решение
