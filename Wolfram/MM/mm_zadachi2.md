## Задача 5

Време на полуразпад:
T = 1620 г.

Закон на разпада:
m(t) = m₀ · 2^(−t/T)

Условие:
m(t) = (2/3) m₀

Следва:
2^(−t/T) = 2/3
−t/T = log₂(2/3)
t = T · log₂(3/2)

**Отговор:**
t = 1620 · log₂(3/2) години

## Задача 11

**Уравнение на Ферхулст**

N' = N (1 − N/2)
N(0) = N₀

Решение:
N(t) = 2 / [1 + (2/N₀ − 1) e^(−t)]

Качествено поведение:

* 0 < N₀ < 2 → N(t) → 2
* N₀ > 2 → N(t) → 2
* N₀ = 2 → N(t) = 2
* N₀ = 0 → N(t) = 0
