Законът на Галилей е:

x = ½ g t²

Размерности:
[x] = L (дължина)
[t] = T (време)
[g] = L/T² (ускорение)

Дясната страна: [g t²] = (L/T²)·T² = L
Лявата страна: [x] = L

И двете страни имат една и съща размерност L.

Това означава, че уравнението е размерностно съгласувано.
Безразмерният множител ½ е универсален.

Следователно, ако променим мерните единици:
- за дължина: нов = k·стар
- за време: нов = m·стар

числените стойности ще се променят, но формата на закона ще остане същата:
x' = ½ g' t'²

Заключение: Законът НЕ зависи от избора на мащаб или мерни единици.

## 7
Модел на конкуренция между два вида (Лотка–Волтера)

Система:

Ṅ₁ = (2 - 3N₁ - N₂)N₁

Ṅ₂ = (5 - 6N₁ - 2N₂)N₂

Параметри:
r₁ = 2, r₂ = 5
a₁₁ = 3, a₁₂ = 1
a₂₁ = 6, a₂₂ = 2

Равновесия:
1. E₀ = (0,0)
2. E₁ = (2/3, 0)
3. E₂ = (0, 5/2)

Проверка за равновесие с двата вида:

2 - 3N₁ - N₂ = 0  ⇒  N₂ = 2 - 3N₁

5 - 6N₁ - 2(2 - 3N₁) = 5 - 6N₁ - 4 + 6N₁ = 1 ≠ 0

→ Няма равновесие с N₁>0, N₂>0.

Устойчивост:

1. E₀ = (0,0):
   J = [[2, 0], [0, 5]]
   λ₁ = 2, λ₂ = 5 > 0 ⇒ неустойчиво.

2. E₁ = (2/3, 0):
   J = [[-2, -2/3], [0, 1]]
   λ₁ = -2, λ₂ = 1 ⇒ седлова точка (неустойчиво).

3. E₂ = (0, 5/2):
   J = [[-1/2, 0], [-15, -5]]
   λ₁ = -1/2, λ₂ = -5 ⇒ асимптотично устойчиво.

Динамично поведение:
- Равновесието (0, 5/2) е глобално асимптотично устойчиво
  за всяко N₂(0) > 0.
- Вид N₂ изтласква N₁ при всички начални условия с N₂(0) > 0.
- Това е пример на конкурентно изключване.

## 8

Дискретен логистичен модел (Рикер):

N(t+1) = 2 N(t) [1 - N(t)/6]

Равновесия (N* = N*):
N* = 2 N* [1 - N*/6]

1) N* = 0
2) 1 = 2[1 - N*/6]  =>  1 = 2 - N*/3  =>  N*/3 = 1  =>  N* = 3

Производна:

f(N) = 2N - (1/3)N²

f'(N) = 2 - (2/3)N

Устойчивост:

f'(0) = 2 > 1  =>  N* = 0 неустойчиво

f'(3) = 2 - 2 = 0 < 1  =>  N* = 3 устойчиво (супер-устойчиво)

Поведение:
- Ако N(0) = 0: N(t) ≡ 0
- Ако N(0) = 3: N(t) ≡ 3
- Ако 0 < N(0) < 6: N(t) → 3 бързо
- Ако N(0) > 6: N(1) < 0 (небиологично)

Конкретно за N(0) = 3:

N(0) = 3

N(1) = 2·3·[1 - 3/6] = 6·(1/2) = 3

N(2) = 3

...

⇒ N(t) = 3 за всяко t.
