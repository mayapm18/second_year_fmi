## Задача 5

Дадено:
T = 1620 г.

Закон на радиоактивния разпада:
m(t) = m₀ · 2^(−t/T)

Условие:
m(t) = (2/3) m₀

Следва:
2^(−t/T) = 2/3
−t/T = log₂(2/3)
t = T · log₂(3/2)

Отговор:
t = 1620 · log₂(3/2) години

## Задача 11

Решете уравнението на Ферхюлст:

N'(t) = N (1 − N/2)
N(0) = N₀

**Решение:**

dN / (N (1 − N/2)) = dt

Разлагане:
1 / (N (1 − N/2)) = 1/N + 1/(2 − N)

Интегриране:
ln|N| − ln|2 − N| = t + C

ln( N / (2 − N) ) = t + C

N / (2 − N) = C e^t

N(t) = 2 C e^t / (1 + C e^t)

От началното условие:
C = N₀ / (2 − N₀)

**Решение:**

N(t) = 2 N₀ e^t / (2 − N₀ + N₀ e^t)

**Качествено поведение:**

• N₀ = 0 → N(t) = 0
• 0 < N₀ < 2 → N(t) → 2
• N₀ = 2 → N(t) = 2
• N₀ > 2 → N(t) ↓ 2

## Задача 14

**Дефиниции:**

Нека x' = f(x), x = 0 е равновесие.

**Функция на Ляпунов:**
V(x) > 0 за x ≠ 0, V(0) = 0

**Устойчивост по Ляпунов:**
за всяко ε > 0 съществува δ > 0 така, че
||x(0)|| < δ ⇒ ||x(t)|| < ε за всички t ≥ 0

**Асимптотична устойчивост:**
устойчивост по Ляпунов и
x(t) → 0 при t → ∞
