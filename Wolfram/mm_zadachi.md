Модел за разпространение на зараза БЕЗ изолация (SI модел)

1. Променливи:
- N – общ брой индивиди (постоянен)
- S(t) – брой здрави (чувствителни) към време t
- I(t) – брой заразени (инфекциозни) към време t
  S(t) + I(t) = N (затворена популация)

2. Параметри:
- β > 0 – коефициент на заразяване
  Той включва вероятност за предаване при контакт и честота на контактите.

3. Уравнения (диференциални):
   dS/dt = -β·(S·I)/N   (здравите намаляват)
   dI/dt = β·(S·I)/N    (заразените нарастват)

4. Свеждане до едно уравнение:
   От S = N - I получаваме:
   dI/dt = β·((N - I)·I)/N
   Това е логистично уравнение с капацитет N.

5. Решение (явен вид):
   I(t) = N / [1 + ((N - I₀)/I₀)·e^(-β·t)]
   където I₀ = I(0) > 0

6. Гранично поведение:
   При t → ∞: I(t) → N
   Тоест всички индивиди в популацията се заразяват.

7. Извод:
   Без изолация (и без възстановяване) заразата завладява цялата популация.
   Това е най-песимистичният сценарий за епидемия.

8. Приложение:
   Моделът описва заболявания, при които:
   - Няма имунитет след преболедуване
   - Няма смъртност от болестта
   - Няма изолация на болните

МОДЕЛ НА БЕРНУЛИ (1760) за едра шарка

Променливи:
- N(t) – оцелели от родова група
- X(t) – оцелели, които НЕ са боледували от едра шарка (податливи)
- z(t) = X(t)/N(t) – част на незаболелите

Параметри:
- β – скорост на заразяване
- ν – смъртност сред заразените (0 < ν < 1)
- µ(t) – смъртност от други причини

Мотивация:
Да се оцени ползата от ваксинацията.
Бернули иска да сравни:
- Брой жертви БЕЗ ваксина
- Брой жертви С ваксина
За целта трябва модел, предвиждащ колко хора ще се разболеят през живота си.

Уравнения:
1) dX/dt = [-β + µ(t)]X
2) dN/dt = -νβX - µ(t)N
3) За z = X/N:  dz/dt = -β z (1 - ν z)

Начално условие:
z(0) = 1  (всички новородени са здрави)

Анализ:
- z(t) намалява
- Устойчива точка: z=0
- z(t) → 0 при t→∞

Заключение:
Без ваксина всеки човек рано или късно се разболява → подкрепя ваксинацията.

Значение:
Първи математически модел в епидемиологията, използван за оценка на общественоздравеопазни мерки.


## Задача 11

Решете уравнението на Ферхюлст:

N'(t) = N (1 − N/2)
N(0) = N₀

**Решение:**

dN / (N (1 − N/2)) = dt

Разлагане:
1 / (N (1 − N/2)) = 1/N + 1/(2 − N)

Интегриране:
ln|N| − ln|2 − N| = t + C

ln( N / (2 − N) ) = t + C

N / (2 − N) = C e^t

N(t) = 2 C e^t / (1 + C e^t)

От началното условие:
C = N₀ / (2 − N₀)

**Решение:**

N(t) = 2 N₀ e^t / (2 − N₀ + N₀ e^t)

**Качествено поведение:**

• N₀ = 0 → N(t) = 0
• 0 < N₀ < 2 → N(t) → 2
• N₀ = 2 → N(t) = 2
• N₀ > 2 → N(t) ↓ 2
