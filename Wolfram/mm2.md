# §3

## 1. **ОСНОВЕН МОДЕЛ: ЗАКОН НА МАЛТУС**

### Уравнението:
```
dN/dt = ε·N
```
Това е **НАЙ-ВАЖНОТО УРАВНЕНИЕ** в главата!

**Как се получава:**
1. **Наблюдение:** Скоростта на промяна зависи от текущото количество
2. **Предположение:** Пропорционална зависимост
3. **Записване:** dN/dt ∝ N → dN/dt = ε·N

### Решението:
```
N(t) = N₀·e^(ε·t)
```
където:
- N₀ = начално количество (при t=0)
- ε = коефициент на прираст

**Запомни:** Решението ВИНАГИ е експоненциална функция!

---

## 2. **ТРИ КЛЮЧОВИ ПАРАМЕТРА**

### 1. Коефициент на прираст (ε)
```
ε = (1/N)·(dN/dt)
```
- Положителен (ε > 0): **растеж**
- Отрицателен (ε < 0): **разпад**
- Нула (ε = 0): **няма промяна**

### 2. Време за удвояване (T₂)
```
T₂ = ln(2)/ε    (за ε > 0)
```
**Пример:** Ако ε=0.01 (1% растеж), тогава:
```
T₂ = ln(2)/0.01 ≈ 0.693/0.01 = 69.3 единици време
```

### 3. Време на полуразпад (T₁/₂)
```
T₁/₂ = ln(2)/|ε|    (за ε < 0)
```
За радиоактивен разпад: λ = |ε|

---

## 3. **ЧЕТИРИ ОСНОВНИ ПРИЛОЖЕНИЯ**

### Приложение 1: Популационен растеж
**Задача от упражнение 3.1:**
- 1650 г.: N = 6×10⁸
- 1950 г.: N = 2.8×10⁹
- t = 300 години

**Решение:**
1. N(t) = N₀·e^(ε·t)
2. 2.8×10⁹ = 6×10⁸·e^(ε·300)
3. e^(ε·300) = 2.8×10⁹ / 6×10⁸ = 4.667
4. ε·300 = ln(4.667) ≈ 1.541
5. ε ≈ 0.005136 годишно

**Проверка:** 
- ε ≈ 0.5% годишно (реално ≈1.2% поради по-точен модел)

### Приложение 2: Лихви в банка
**Важен детайл:**
- Непрекъснато: Q(t) = Q₀·e^(r·t)
- Дискретно: Q(n) = Q₀·(1 + r)ⁿ

**Неравенство на Бернули:**
```
e^(r·n) > (1 + r)ⁿ    за r > 0
```
**Защо е важно:** Банките използват дискретно начисляване, защото е по-изгодно за тях!

### Приложение 3: Инфлация
**Уравнение:** dQ/dt = -μ·Q

**Важен извод:**
Ако инфлацията е μ и индексацията е също μ, пак имаш загуба!
```
Реална стойност след 1 година: Q₀·e^(-μ)
След индексация: Q₀·(1+μ)·e^(-μ)
Тъй като (1+μ)·e^(-μ) < 1, имаш загуба!
```

**Пример от упражнение 3.3:**
- μ = 10% = 0.1
- След индексация: (1+0.1)·e^(-0.1) = 1.1×0.9048 ≈ 0.9953
- **Загуба:** 1 - 0.9953 = 0.0047 = **0.47%**

### Приложение 4: Радиоактивен разпад
**Модел:** dM/dt = -λ·M

**За датиране с C¹⁴:**
1. Животно/растение акумулира C¹⁴ докато е живо
2. След смъртта започва разпад
3. Измерваме M(t) - останалото количество
4. Първоначалното M₀ се знае (от съвременни образци)
5. Възраст: t = -(1/λ)·ln[M(t)/M₀]

**Пример от упражнение 3.6:**
- M(t)/M₀ = 20% = 0.2
- T₁/₂ за C¹⁴ = 5600 години
- λ = ln(2)/5600 ≈ 0.0001238
- t = -ln(0.2)/0.0001238 ≈ 12930 години

## 4. **СТАЦИОНАРНИ СЪСТОЯНИЯ и УСТОЙЧИВОСТ - СТЪПКА ПО СТЪПКА**

### Стъпка 1: Намиране на стационарни точки
За уравнение: dN/dt = f(N)
Стационарни точки: f(N*) = 0

**Пример за Малтус:** f(N) = ε·N
- f(N*) = ε·N* = 0
- Единствено решение: **N* = 0**

### Стъпка 2: Проверка за устойчивост
1. Нека N = N* + n(t), където |n| ≪ |N*|
2. Развиваме f(N* + n) в ред на Тейлър:
   ```
   f(N* + n) = f(N*) + f'(N*)·n + малки членове
             = 0 + A·n + малки членове
   ```
   където A = f'(N*)

3. Линеаризирано уравнение:
   ```
   dn/dt = A·n
   ```

4. Решение: n(t) = n₀·e^(A·t)

### Стъпка 3: Анализ
- **Ако A < 0:** n(t) → 0 → **УСТОЙЧИВО**
- **Ако A > 0:** n(t) → ∞ → **НЕУСТОЙЧИВО**
- **Ако A = 0:** не може да се реши от линеаризацията

**Пример за Малтус:**
- f(N) = ε·N
- f'(N) = ε
- A = ε
- При ε > 0: неустойчиво (растеж)
- При ε < 0: устойчиво (разпад)

---

## 5. **РАЗЛИКА МЕЖДУ ДИСКРЕТНО и НЕПРЕКЪСНАТО**

### Непрекъснат модел:
```
dN/dt = ε·N  →  N(t) = N₀·e^(ε·t)
```
- Промяната се случва постоянно
- Добро приближение за големи популации
- Използва се за теоретични изследвания

### Дискретен модел:
```
N_{k+1} = N_k + ε·N_k = (1+ε)·N_k
```
- Промяната се случва на определени интервали
- По-реалистично за много процеси
- Решение: N_k = N₀·(1+ε)^k

### Сравнение:
```
e^(ε·t) vs (1+ε)^t
```
За малки ε:
```
e^ε ≈ 1 + ε + ε²/2 + ...
(1+ε) = 1 + ε
```
Разликата е от порядъка на ε²/2

---

## 6. **КЛЮЧОВИ ФОРМУЛИ за ЗАПОМНЯНЕ**

1. **Основно уравнение:** dN/dt = ε·N
2. **Решение:** N(t) = N₀·e^(ε·t)
3. **Време за удвояване:** T₂ = ln(2)/ε
4. **Време на полуразпад:** T₁/₂ = ln(2)/|ε|
5. **Отношение в момент t:** N(t)/N₀ = e^(ε·t)
6. **Време за промяна с фактор k:** t = (1/ε)·ln(k)

---

## 7. **КАК ДА РЕШАВАШ ЗАДАЧИ - АЛГОРИТЪМ**

### Задача тип 1: Намиране на ε
**Дадено:** N₀, N(t) за дадено t
**Търси се:** ε

**Решение:**
1. N(t) = N₀·e^(ε·t)
2. e^(ε·t) = N(t)/N₀
3. ε·t = ln[N(t)/N₀]
4. ε = (1/t)·ln[N(t)/N₀]

### Задача тип 2: Намиране на време
**Дадено:** N₀, ε, N(t) (или колко пъти е променено)
**Търси се:** t

**Решение:**
1. N(t) = N₀·e^(ε·t)
2. e^(ε·t) = N(t)/N₀ = k
3. ε·t = ln(k)
4. t = (1/ε)·ln(k)

### Задача тип 3: Стационарни точки и устойчивост
**Дадено:** Уравнение dN/dt = f(N)
**Търси се:** Стационарни точки и тяхната устойчивост

**Решение:**
1. Намери N*: f(N*) = 0
2. Изчисли A = f'(N*)
3. Анализирай:
   - Ако A < 0 → устойчиво
   - Ако A > 0 → неустойчиво
   - Ако A = 0 → не може да се каже

---

## 8. **ЧЕСТИ ГРЕШКИ и КАК ДА ИЗБЕГНЕШ**

### Грешка 1: Забравяне на абсолютната стойност
За време на полуразпад: T₁/₂ = ln(2)/|ε|
Ако ε < 0, трябва |ε|!

### Грешка 2: Невярни единици
ε трябва да е в правилни единици!
Ако t е в години, ε е 1/година
Ако t е в дни, ε е 1/ден

### Грешка 3: Грешно прилагане на ln
Ако N(t)/N₀ = k, то:
- Правилно: ε·t = ln(k)
- Грешно: ε·t = k (често срещана грешка!)

### Грешка 4: Объркване на растеж и разпад
- Растеж: ε > 0, N(t) расте
- Разпад: ε < 0, N(t) намалява
- Провери: Ако N(t) < N₀, тогава ε трябва да е отрицателно!

---

## 9. **ВАЖНИ ЧИСЛЕНИ СТОЙНОСТИ**

За малки x:

## 1. **ОХЛАЖДАНЕ НА ТЯЛО - ЗАКОН НА НЮТОН**

### Основно уравнение:
```
dθ/dt = -μ(θ - T)
```
където:
- θ = температура на тялото
- T = температура на околната среда (T < θ за охлаждане)
- μ = коефициент на охлаждане

### Решение:
```
θ(t) = (θ₀ - T)·e^(-μ·t) + T
```

### Важни свойства:
1. **Стационарна точка:** θ = T (устойчива)
2. **Експоненциално намаляване** на разликата θ - T
3. Може да описва и **затопляне**, ако T > θ

### Пример 4.1: Кафето (много важен!)
**Дадено:**
- θ₀ = 90°C (начална температура)
- T = 20°C (стая)
- В 16:00: θ = 70°C
- В 16:15: θ = 40°C
- Налято в t=0

**Решение:**
1. Записваме решението: θ(t) = 70·e^(-μ·t) + 20
   (70 = 90-20)
   
2. В момент x (16:00):
   ```
   70 = 70·e^(-μ·x) + 20
   50 = 70·e^(-μ·x)
   e^(-μ·x) = 5/7
   ```

3. В момент x+0.25 (16:15):
   ```
   40 = 70·e^(-μ·(x+0.25)) + 20
   20 = 70·e^(-μ·(x+0.25))
   e^(-μ·(x+0.25)) = 2/7
   ```

4. Делим двете уравнения:
   ```
   e^(-μ·x) / e^(-μ·(x+0.25)) = (5/7) / (2/7)
   e^(0.25μ) = 5/2 = 2.5
   ```

5. Решаваме:
   ```
   0.25μ = ln(2.5) ≈ 0.9163
   μ ≈ 3.665 1/час
   ```

6. Намираме x:
   ```
   e^(-3.665·x) = 5/7
   -3.665·x = ln(5/7) ≈ -0.3365
   x ≈ 0.0918 часа ≈ 5.5 минути
   ```

7. Кафето е наляно в 15:54:30

## 2. **СВОБОДНО ПАДАНЕ В СРЕДА**

### Стоксов закон (линейно съпротивление):
```
R = k·m·v
```
където:
- R = съпротивителна сила
- k = коефициент
- m = маса
- v = скорост

### Уравнение на движението:
```
m·dv/dt = mg - R = mg - kmv
dv/dt = g - kv
```

### Решение:
```
v(t) = (v₀ - g/k)·e^(-kt) + g/k
```

### Важни свойства:
1. **Гранична скорост:** v∞ = g/k
2. Независимо от v₀, v(t) → v∞
3. Стационарна точка: v = g/k (устойчива)

### Квадратично съпротивление (при по-големи скорости):
```
R = mg·k²·v²
```
Уравнение: `dv/dt = g - gk²v²`

Решение: `v(t) = (1/k)·tanh(kgt)`

Гранична скорост: v∞ = 1/k

## 3. **РАЗПРОСТРАНЕНИЕ НА БОЛЕСТИ - БЕЗ ИЗОЛАЦИЯ**

### Модел:
```
dx/dt = α·x·(1 - x)
```
където:
- x = част от популацията, която е боледуваща
- (1-x) = част от популацията, която е здрава
- α = коефициент на разпространение

### Свойства:
1. **Стационарни точки:** x=0 и x=1
2. **Устойчивост:**
   - f'(0) = α > 0 → **неустойчиво**
   - f'(1) = -α < 0 → **устойчиво**
3. Ако x₀ > 0, то x(t) → 1 при t→∞
4. **Заключение:** Без изолация, цялата популация ще се зарази!

---

## 4. **РАЗПРОСТРАНЕНИЕ НА БОЛЕСТИ - СЪС ИЗОЛАЦИЯ**

### Два уравнения:
1. **Носители на заразата (изолират се):**
   ```
   dy/dt = -μ·y  →  y(t) = y₀·e^(-μt)
   ```

2. **Податливи индивиди (заразяват се):**
   ```
   dx/dt = α·x·y
   ```

### Решение:
Заместваме y(t) в dx/dt:
```
dx/dt = α·x·y₀·e^(-μt)
dx/x = α·y₀·e^(-μt)dt
ln(x) = -(α·y₀/μ)·e^(-μt) + C
```

С x(0)=x₀:
```
x(t) = x₀·exp[(α·y₀/μ)·(1 - e^(-μt))]
```

### Максимален брой заразени:
```
x_max = x(∞) = x₀·exp(α·y₀/μ)
```

**Важен извод:** Колкото по-бързо се изолират (по-голямо μ), толкова по-малко хора ще се заразят!

## 5. **МОДЕЛ НА БЕРНУЛИ ЗА ЕДРА ШАРКА**

### Променливи:
- N(t) = брой оцелели
- X(t) = брой незаболели
- z(t) = X/N = част от оцелелите, които не са боледували

### Уравнение:
```
dz/dt = -β·z·(1 - ν·z)
```
където:
- β = скорост на заразяване
- ν = смъртност сред заболелите (ν < 1)

### Решение при z(0)=1:
```
z(t) = 1/[ν + (1-ν)·e^(βt)]
```

### Свойства:
1. **Стационарни точки:** z=0 (устойчива) и z=1/ν (неустойчива)
2. z(t) → 0 при t→∞
3. **Заключение:** Ако живееш достатъчно дълго, рано или късно ще се разболееш

### Числен пример (Бернули):
ν = β = 1/8
За t=20 години:
```
z(20) = 1/[(1/8) + (7/8)·e^(20/8)]
      = 1/[0.125 + 0.875·e^(2.5)]
      = 1/[0.125 + 0.875·12.182]
      ≈ 1/[0.125 + 10.659] ≈ 1/10.784 ≈ 0.093
```
Само 9.3% от 20-годишните не са боледували!

## 6. **ХИМИЧЕСКА РЕАКЦИЯ**

### Реакция: P + Q → X

### Уравнение:
```
dx/dt = α·(p-x)·(q-x)
```
където:
- p, q = начални концентрации на P и Q
- x = концентрация на X
- p > x, q > x (реактантите намаляват)

### Свойства:
1. Ако p < q, то x(t) → p при t→∞
2. Функцията f(x) = α(p-x)(q-x) е парабола
3. При x < p, f(x) > 0 → x(t) расте

### Специален случай p = q:
```
dx/dt = α·(p-x)²
```
Решение: `1/(p-x) - 1/p = α·t`

## 7. **ОБЩИ ЗАКОНОМЕРНОСТИ**

### Всички модели имат формата:
```
dN/dt = f(N)
```

### Типове функции f(N):

1. **Линейна:** f(N) = a·N + b
   - Охлаждане: f(θ) = -μ(θ-T)
   - Свободно падане: f(v) = g - kv
   - Малтус: f(N) = εN

2. **Квадратична:** f(N) = a·N·(M-N)
   - Епидемия без изолация: f(x) = αx(1-x)
   - Химична реакция: f(x) = α(p-x)(q-x)
   - Бернули: f(z) = -βz(1-νz)

## 8. **МЕТОДИ ЗА РЕШАВАНЕ**

### Стъпка 1: Определяне на типа уравнение
1. Линейно? → Раздели променливите или използвай формула
2. Квадратично? → Раздели променливите, използвай частични дроби

### Стъпка 2: Решаване
**За линейно:** N(t) = Ce^(at) + (частно решение)

**За квадратично** f(N) = a·N·(b-N):
1. Разделяне: dN/[N(b-N)] = a·dt
2. Интегриране: (1/b)·[ln|N| - ln|b-N|] = a·t + C
3. Решение: N/(b-N) = C·e^(abt)

### Стъпка 3: Определяне на константите
От начални условия

## 9. **КЛЮЧОВИ ФОРМУЛИ за ЗАПОМНЯНЕ**

1. **Охлаждане:** θ(t) = (θ₀-T)e^(-μt) + T
2. **Свободно падане (линейно):** v(t) = (v₀-g/k)e^(-kt) + g/k
3. **Свободно падане (квадратично):** v(t) = (1/k)·tanh(kgt)
4. **Епидемия без изолация:** dx/dt = αx(1-x)
5. **Епидемия с изолация:** x(t) = x₀·exp[(αy₀/μ)(1-e^(-μt))]
6. **Бернули:** z(t) = 1/[ν + (1-ν)e^(βt)]
7. **Химична реакция:** dx/dt = α(p-x)(q-x)

## 10. **ПРАКТИЧЕСКИ СЪВЕТИ**

### Как да разпознаеш типа задача:
1. **Температура/охлаждане:** θ, T, време
2. **Скорост/падене:** v, g, съпротивление
3. **Болести:** x, y, изолация, процент
4. **Химия:** p, q, x, концентрации

### Важни числени методи:
1. За намиране на време: вземи ln от двете страни
2. За намиране на константа: използвай две точки
3. За стационарни точки: реши f(N)=0
4. За устойчивост: изчисли f'(N*)

# §5. Лимитирани Популации - ПЪЛЕН РЪКОВОДСТВО

## 1. **ПРОБЛЕМ С МОДЕЛА НА МАЛТУС**

### Защо Малтус не работи?
```
dN/dt = ε·N → N(t) = N₀·e^(εt)
```
**Проблем:** Експоненциалният растеж е безкраен, но в реалността има ограничения:
- Ограничена храна
- Ограничено пространство  
- Ограничена вода
- Конкуренция

### Решение: Функция на лимитирането
Вместо ε = константа, полагаме:
```
ε(N) = ε₀·[1 - L(N)]
```
където:
- ε₀ = максимален коефициент на прираст (при N→0)
- L(N) = функция на лимитирането
- L(0) = 0 (няма лимит при малко население)
- L(∞) = 1 (пълен лимит при голямо население)

## 2. **ЛОГИСТИЧЕН МОДЕЛ (ФЕРХЮЛСТ)**

### Уравнение:
```
dN/dt = ε₀·N·[1 - (N/K)]
```
или
```
dN/dt = ε₀·N·[1 - γ·N]  (където γ = 1/K)
```

### Параметри:
- **K** = капацитет на средата (ниво на насищане)
- **ε₀** = максимален коефициент на прираст
- **γ** = коефициент на вътревидова конкуренция

### Решение (МНОГО ВАЖНО!):
```
N(t) = K / [1 + ((K - N₀)/N₀)·e^(-ε₀·t)]
```

### Безразмерна форма:
Нека η = N/K и τ = t/T, където T = ln(2)/ε₀:
```
dη/dτ = η·(1 - η)
```

Решението:
```
η(τ) = 1 / [1 + ((1 - η₀)/η₀)·2^(-τ)]
```

## 3. **СВОЙСТВА НА ЛОГИСТИЧНИЯ МОДЕЛ**

### Стационарни точки:
1. **N = 0** (изчезване) → **неустойчиво**
   - f'(0) = ε₀ > 0
   
2. **N = K** (капацитет) → **устойчиво**
   - f'(K) = -ε₀ < 0

### Ключови моменти:

#### 1. Инфлексна точка:
Когато N = K/2, скоростта на растеж е **максимална**:
```
f'(N) = ε₀·(1 - 2N/K) = 0 → N = K/2
f_max = ε₀·K/4
```

#### 2. Форма на кривата:
- **S-образна** (сигмоида)
- Бавен старт (N₀ малко)
- Бърз растеж (N ≈ K/2)
- Забавяне и насищане (N → K)

#### 3. Поведение при различни N₀:
- Ако 0 < N₀ < K → N(t) ↑, N(t) → K
- Ако N₀ > K → N(t) ↓, N(t) → K

## 6. **ПОПУЛАЦИИ С ГРАНИЦА НА ОЦЕЛЯВАНЕ**

### Проблем с логистичния модел:
При N < K, популацията винаги расте → не вярно!
Има популации, които изчезват при твърде малък брой.

### Модел с граница на оцеляване:
```
dN/dt = -ε₀·N·[1 - (N/K)]·[1 - (N/L)]
```
където 0 < K < L

### Стационарни точки:
1. **N = 0** → устойчиво (изчезване)
2. **N = K** → неустойчиво (граница на оцеляване)
3. **N = L** → устойчиво (капацитет)

### Поведение:
- Ако N₀ < K → N(t) → 0 (изчезване)
- Ако K < N₀ < L → N(t) → L (растеж)
- Ако N₀ > L → N(t) → L (намаляване)

### Пример: Пощенски гълъб
- Когато популацията падне под критичната граница K
- Индивидите не могат да намерят партньори
- Популацията изчезва, дори да има достатъчно ресурси

## 7. **КЛАСИФИКАЦИЯ НА МОДЕЛИТЕ**

### Тип I: Неограничен растеж (Малтус)
```
dN/dt = ε·N
```
- Расте до безкрайност
- Нереалистично за дълги периоди

### Тип II: Логистичен (Ферхюлст)
```
dN/dt = ε₀·N·(1 - N/K)
```
- Расте до равновесие K
- S-образна крива
- Максимален растеж при N=K/2

### Тип III: С граница на оцеляване
```
dN/dt = -ε₀·N·(1 - N/K)·(1 - N/L)
```
- Има минимален брой K за оцеляване
- Под K → изчезване
- Над K → растеж до L

## 9. **МЕТОДИ ЗА РЕШАВАНЕ**

### Стъпка 1: Определяне на типа
1. Има ли множител (1 - N/K)? → Логистичен
2. Има ли две граници K и L? → С граница на оцеляване
3. Само ε·N? → Малтус

### Стъпка 2: Записване на уравнението
Общ вид за логистичен:
```
dN/dt = ε₀·N·(1 - N/K)
```

### Стъпка 3: Решаване
1. Раздели променливите:
   ```
   dN/[N(1-N/K)] = ε₀·dt
   ```

2. Разложи на частични дроби:
   ```
   [1/N + 1/(K-N)]dN = ε₀·dt
   ```

3. Интегрирай:
   ```
   ln|N| - ln|K-N| = ε₀·t + C
   ```

4. Експоненцирай:
   ```
   N/(K-N) = C·e^(ε₀·t)
   ```

5. Определи C от N(0)=N₀:
   ```
   C = N₀/(K-N₀)
   ```

6. Получи:
   ```
   N(t) = K / [1 + ((K-N₀)/N₀)·e^(-ε₀·t)]
   ```

### Стъпка 4: Анализ
1. Намери стационарни точки: N=0 и N=K
2. Провери устойчивост: f'(0)>0, f'(K)<0
3. Намери инфлексна точка: N=K/2


2. **Време за достигане на N₁:**
   ```
   t = (1/ε₀)·ln[(N₁·(K-N₀))/(N₀·(K-N₁))]
   ```

3. **Инфлексна точка:**

   Стойност: `N = K/2`
   Скорост: `dN/dt = ε₀·K/4`

4. **Полувреме (от N₀ до K/2):**
   ```
   t_{1/2} = (1/ε₀)·ln[(K-N₀)/N₀]
   ```

## 1. **ОСНОВЕН МОДЕЛ: ПОПУЛАЦИЯ + ХИЩНИЦИ**

### Уравнение:
```
dN/dt = ε₀·N - p
```
където:
- N = брой на популацията
- ε₀ = коефициент на прираст (Малтус)
- p = брой, който хищниците изяждат за единица време

### Решение:
```
N(t) = (N₀ - p/ε₀)·e^(ε₀·t) + p/ε₀
```

### Стационарна точка (равновесие):
```
N* = p/ε₀
```

### Устойчивост:
- f'(N*) = ε₀ > 0 → **НЕУСТОЙЧИВО**

---

## 2. **ТРИ ВАЖНИ СЛУЧАЯ**

### Случай 1: N₀ > N* (N₀ > p/ε₀)
- N₀·ε₀ > p (популацията расте по-бързо, отколкото я ядат)
- N(t) → ∞ при t → ∞
- **Експоненциален растеж**

### Случай 2: N₀ < N* (N₀ < p/ε₀)
- N₀·ε₀ < p (хищниците ядат по-бързо, отколкото расте популацията)
- N(t) = 0 при t = t*
- **Изчезване след краен период**

### Случай 3: N₀ = N* (N₀ = p/ε₀)
- N₀·ε₀ = p (идеален баланс)
- N(t) = N* = константа
- **Стабилна популация**

---

## 3. **ВРЕМЕ НА ИЗЧЕЗВАНЕ t***

Ако N₀ < p/ε₀, популацията изчезва при:
```
t* = (1/ε₀)·ln[p/(p - N₀·ε₀)]
```

**Доказателство:**
От N(t*) = 0:
```
0 = (N₀ - p/ε₀)·e^(ε₀·t*) + p/ε₀
(p/ε₀)·e^(ε₀·t*) = (p/ε₀ - N₀)·e^(ε₀·t*)
e^(ε₀·t*) = p/(p - N₀·ε₀)
ε₀·t* = ln[p/(p - N₀·ε₀)]
t* = (1/ε₀)·ln[p/(p - N₀·ε₀)]
```

## 5. **ЛИМИТИРАНА ПОПУЛАЦИЯ + ХИЩНИЦИ**

### Уравнение (Ферхулст + хищници):
```
dN/dt = ε₀·N·(1 - N/K) - p
```

### Анализ:
Функцията е параболата на Ферхулст, преместена надолу с p:
```
F(N) = f(N) - p, където f(N) = ε₀·N·(1 - N/K)
```

### Три случая:

#### Случай A: p < ε₀·K/4
- f_max = ε₀·K/4
- Две стационарни точки: N₁ и N₂
- 0 < N₁ < K/2 < N₂ < K
- **N₁** неустойчиво (граница на оцеляване)
- **N₂** устойчиво (нов капацитет)

#### Случай B: p = ε₀·K/4
- Една стационарна точка: N* = K/2
- **Полуустойчиво**: отгоре → устойчиво, отдолу → неустойчиво

#### Случай C: p > ε₀·K/4
- Няма стационарни точки
- F(N) < 0 за всички N
- Популацията винаги изчезва

## 6. **ОПТИМИЗАЦИЯ НА РИБОЛОВ**

### Модел:
```
dN/dt = ε₀·N·(1 - N/K) - E·N
```
където:
- E = интензитет на риболова
- E·N = улов за единица време

### Преобразуване:
Уравнението може да се запише като логистично:
```
dN/dt = (ε₀ - E)·N·[1 - N/((1 - E/ε₀)·K)]
```
Нови параметри:
- ε = ε₀ - E (ефективен коефициент на прираст)
- R = (1 - E/ε₀)·K (ефективен капацитет)

### Условие за устойчивост:
```
E < ε₀
```
Иначе популацията изчезва.

### Стационарно състояние:
```
N* = R = (1 - E/ε₀)·K
```

### Ефективност на риболова:
Улов за единица време в стационарен режим:
```
Y(E) = E·N* = E·K·(1 - E/ε₀)
```

### Оптимизация:
Търсим E, което максимизира Y(E):
1. Y(E) = K·(E - E²/ε₀) (парабола)
2. Максимум при E = ε₀/2
3. Максимален улов: Y_max = (ε₀·K)/4

**Оптимална стратегия:**
```
E_opt = ε₀/2
N*_opt = K/2
Y_max = ε₀·K/4
```


където:
- N₁, N₂ = числености на двата вида
- ε₁, ε₂ = коефициенти на прираст (без конкуренция)
- γ₁, γ₂ = коефициенти на "лакомство" (колко храна изяжда индивид)
- F(N₁,N₂) = общо количество изядена храна

---

## 2. **ФИЗИЧЕСКИ СМИСЪЛ**

### Коефициент на прираст ε:
- Колко бързо се размножава видът при изобилие на храна
- По-голям ε = по-бързо размножаване

### Коефициент на лакомство γ:
- Колко храна изяжда един индивид
- По-голям γ = по-голяма потребност от храна
- Ако γ₁ > γ₂ → вид 1 е "по-лаком"

### Функция F(N₁,N₂):
- Общо количество изядена храна за единица време
- F(0,0) = 0 (без животни → няма изядена храна)
- F расте с N₁ и N₂ (повече животни → повече изядена храна)

---

## 3. **КЛЮЧОВ ПАРАМЕТЪР: χ**

### Дефиниция:
```
χ = γ₂·ε₁ - γ₁·ε₂ = γ₁·γ₂·(ε₁/γ₁ - ε₂/γ₂)
```

### Значение:
χ показва **кой вид ще спечели** конкурентната битка!

### Три случая:

#### Случай 1: χ > 0
```
ε₁/γ₁ > ε₂/γ₂
```
- **Вид 1 спечелва**
- Вид 2 изчезва (N₂ → 0)
- **Ефективността на вид 1 е по-голяма**

#### Случай 2: χ < 0
```
ε₁/γ₁ < ε₂/γ₂
```
- **Вид 2 спечелва**
- Вид 1 изчезва (N₁ → 0)
- **Ефективността на вид 2 е по-голяма**

#### Случай 3: χ = 0
```
ε₁/γ₁ = ε₂/γ₂
```
- Може да има равновесие
- И двата вида могат да съществуват
- Зависи от функцията F

---

## 4. **ИНТЕГРАЛ НА СИСТЕМАТА**

### Важно съотношение:
От уравненията получаваме:
```
(N₁^γ₂) / (N₂^γ₁) = C·e^(χ·t)
```
където C се определя от началните условия.

### Тълкуване:

**Ако χ > 0:**
- (N₁^γ₂)/(N₂^γ₁) → ∞ при t→∞
- Това означава N₂ → 0 (вид 2 изчезва)
- N₁ остава краен (стига до равновесие)

**Ако χ < 0:**
- (N₁^γ₂)/(N₂^γ₁) → 0 при t→∞
- Това означава N₁ → 0 (вид 1 изчезва)
- N₂ остава краен (стига до равновесие)

---

## 5. **РАВНОВЕСИЕ (χ = 0)**

### Условие:
```
ε₁/γ₁ = ε₂/γ₂
```

### Физически смисъл:
**Ефективността на двата вида е равна!**

Ефективност = прираст/лакомство
- Колко бързо се размножаваш, отнесено към това колко ядеш
- Видове с по-висока ефективност печелят

### При χ = 0 имаме интеграл:
```
N₁^γ₂ = C·N₂^γ₁
```

Това означава, че N₁ и N₂ са свързани - не могат да се променят независимо.

### Равновесни точки:
Намират се от системата:
1. ε₁ - γ₁·F(N₁,N₂) = 0
2. ε₂ - γ₂·F(N₁,N₂) = 0

При χ = 0 двете уравнения са еквивалентни, така че имаме едно уравнение с две неизвестни → безкрайно много решения по една крива.

---

## 6. **КОЙ ВИД ИЗЧЕЗВА? - ПРАВИЛО**

### Правило 1:
**При равни ε (ε₁ = ε₂):**
Изчезва **по-лакомият** вид (този с по-голямо γ)

**Доказателство:**
χ = γ₂·ε₁ - γ₁·ε₂ = ε·(γ₂ - γ₁)
- Ако γ₁ > γ₂ → χ < 0 → изчезва вид 1
- Ако γ₁ < γ₂ → χ > 0 → изчезва вид 2

### Правило 2:
**При равни γ (γ₁ = γ₂):**
Изчезва **по-бавно размножаващият се** (този с по-малко ε)

**Доказателство:**
χ = γ·(ε₁ - ε₂)
- Ако ε₁ > ε₂ → χ > 0 → изчезва вид 2
- Ако ε₁ < ε₂ → χ < 0 → изчезва вид 1

### Правило 3:
**В общия случай:**
Изчезва видът с **по-ниска ефективност** ε/γ

---

## 7. **СЛЕД ИЗЧЕЗВАНЕ НА ЕДИН ВИД**

### Да предположим, че вид 2 изчезва:
Тогава N₂ = 0 и имаме само вид 1:
```
dN₁/dt = [ε₁ - γ₁·F(N₁,0)]·N₁
```

Но F(N₁,0) зависи само от N₁ → можем да запишем:
```
dN₁/dt = ε₁·[1 - L(N₁)]·N₁
```
където L(N₁) = (γ₁/ε₁)·F(N₁,0)

### Това е **лимитиран модел** (като Ферхюлст)!

Свойства на L(N₁):
1. L(0) = 0 (при малко население, няма лимит)
2. L монотонно расте (повече животни → повече конкуренция)
3. L(∞) = 1 (при много население, пълен лимит)

### Равновесие за вид 1:
От уравнение L(N₁*) = 1 получаваме N₁* → устойчиво равновесие

---

## 8. **ЕКОЛОГИЧЕН БАЛАНС**

### Кога е възможно екологично равновесие?
Само при **χ = 0** (ε₁/γ₁ = ε₂/γ₂)

### При χ ≠ 0:
- Всеки от видовете се опитва да максимизира ε/γ
- Този с по-висока ефективност изтласква другия
- **Конкурентно изключване** - един вид елиминира другия

### При χ = 0:
- И двата вида имат еднаква ефективност
- Могат да съществуват заедно
- Но равновесието е **нестабилно** - малки отклонения водят до доминация на единия вид

---

## 9. **ПРИМЕРИ**

### Пример 1: Говеда (ε=0.3, γ=0.5) vs Овце (ε=0.2, γ=0.3)
```
Ефективност говеда: 0.3/0.5 = 0.6
Ефективност овце: 0.2/0.3 ≈ 0.667
```
Овцете имат по-висока ефективност → овцете печелят!

### Пример 2: Бързо размножаващ се, но лаком вид vs бавно размножаващ се, но икономичен вид
- Вид A: ε=0.8, γ=1.0 → ефективност = 0.8
- Вид B: ε=0.4, γ=0.4 → ефективност = 1.0
- **Вид B печели!** Икономичността е по-важна от скоростта на размножаване

---

## 10. **КЛЮЧОВИ ФОРМУЛИ**

1. **Уравнения:**
   ```
   dN₁/dt = [ε₁ - γ₁·F(N₁,N₂)]·N₁
   dN₂/dt = [ε₂ - γ₂·F(N₁,N₂)]·N₂
   ```

2. **Параметър χ:**
   ```
   χ = γ₂·ε₁ - γ₁·ε₂ = γ₁·γ₂·(ε₁/γ₁ - ε₂/γ₂)
   ```

3. **Интеграл:**
   ```
   (N₁^γ₂)/(N₂^γ₁) = C·e^(χ·t)
   ```

4. **Условие за равновесие:**
   ```
   ε₁/γ₁ = ε₂/γ₂
   ```

5. **Ефективност на вид:**
   ```
   Ефективност = ε/γ
   ```

---

## 11. **ПРАКТИЧЕСКИ СЪВЕТИ ЗА РЕШАВАНЕ**

### Стъпка 1: Определяне на параметрите
1. Прочети условието внимателно
2. Идентифицирай ε₁, ε₂, γ₁, γ₂
3. Определи коефициентите на "лакомство" и "прираст"

### Стъпка 2: Изчисляване на χ
```
χ = γ₂·ε₁ - γ₁·ε₂
```

### Стъпка 3: Анализ
1. **Ако χ > 0:** Вид 1 печели, вид 2 изчезва
2. **Ако χ < 0:** Вид 2 печели, вид 1 изчезва  
3. **Ако χ = 0:** Може да има равновесие

### Стъпка 4: Проверка на специални случаи
1. **При равни ε:** Изчезва по-лакомият
2. **При равни γ:** Изчезва по-бавният
3. **Винаги:** Изчезва този с по-ниска ε/γ

### Стъпка 5: Определяне на поведението след изчезване
1. Ако изчезне един вид, останалият се подчинява на лимитиран модел
2. Намери равновесната му стойност от L(N*) = 1

---

## 12. **ИНТУИТИВНО ОБЯСНЕНИЕ**

### Мисли така:
**Ефективност = "Умение за оцеляване"**

1. **Висок ε:** Бързо се размножаваш → повече потомци
2. **Нисък γ:** Малоядец → оцеляваш при недостиг на храна
3. **ε/γ:** Баланс между размножаване и консумация

**Пример от бизнеса:**
- ε = растеж на фирмата (% увеличение на печалбата)
- γ = оперативни разходи
- ε/γ = ефективност на бизнеса
- Фирмата с по-висока ефективност изтласква конкурента!

### В природата:
- Видове с висока ефективност (ε/γ) доминират
- При равни условия, икономичните видове печелят
- Конкуренцията води до оптимизация на ε/γ

---

## 13. **ЧЕСТО СРЕЩАНИ ГРЕШКИ**

1. **Объркване на ε и γ:** ε е за растеж, γ е за консумация
2. **Забравяне да сравниш ε/γ:** Това е ключовият параметър!
3. **Грешна интерпретация на χ:** χ>0 не означава, че N₁ расте, а че N₁/N₂ расте
4. **Забравяне, че след изчезването има лимитиран модел**
5. **Мислене, че при χ=0 винаги има равновесие:** Трябва и F да позволи това

**Запомни:** В конкуренцията печели не най-бързият и не най-силният, а **най-ефективният**!

-----------------

# §8. Модел "Хищник-Жертва" (Лотка-Волтера) - ЦЯЛОСТНО РЪКОВОДСТВО

## 1. **ОСНОВНА ИДЕЯ**

### Ситуация:
Два вида взаимодействат:
- **Вид 1: Жертви** (зайци, риби, растителнояди)
- **Вид 2: Хищници** (вълци, лисици, рибояди)

### Ключова зависимост:
- Колкото повече хищници, толкова по-бавно растат жертвите
- Колкото повече жертви, толкова по-бързо растат хищниците

---

## 2. **УРАВНЕНИЯ НА ЛОТКА-ВОЛТЕРА**

### Система уравнения:
```
dN₁/dt = (ε₁ - γ₁·N₂)·N₁
dN₂/dt = (-ε₂ + γ₂·N₁)·N₂
```

### Параметри:
- **N₁** = брой жертви
- **N₂** = брой хищници
- **ε₁** > 0: коефициент на прираст на жертвите (без хищници)
- **ε₂** > 0: коефициент на смъртност на хищниците (без храна)
- **γ₁** > 0: колко хищници влияят на жертвите
- **γ₂** > 0: колко жертви влияят на хищниците

### Физически смисъл:
1. **За жертвите:** 
   - Без хищници (N₂=0): dN₁/dt = ε₁·N₁ (експоненциален растеж)
   - С хищници: растежът намалява с γ₁·N₂·N₁

2. **За хищниците:**
   - Без храна (N₁=0): dN₂/dt = -ε₂·N₂ (експоненциален разпад)
   - С храна: разпадът се компенсира с γ₂·N₁·N₂

---

## 3. **СТАЦИОНАРНИ ТОЧКИ (РАВНОВЕСИЕ)**

### Намиране на равновесие:
Полагаме dN₁/dt = 0 и dN₂/dt = 0:

1. От dN₁/dt = 0:
   ```
   (ε₁ - γ₁·N₂)·N₁ = 0
   ```
   Или N₁ = 0, или N₂ = ε₁/γ₁

2. От dN₂/dt = 0:
   ```
   (-ε₂ + γ₂·N₁)·N₂ = 0
   ```
   Или N₂ = 0, или N₁ = ε₂/γ₂

### Четири възможни равновесия:

#### 1. **Тривиално (0,0):**
```
N₁ = 0, N₂ = 0
```
- И двата вида са изчезнали
- Неинтересно от биологична гледна точка

#### 2. **Само хищници (0, ε₁/γ₁):**
```
N₁ = 0, N₂ = ε₁/γ₁
```
- Жертвите са изчезнали
- Хищниците ще изчезнат след това (нямат храна)

#### 3. **Само жертви (ε₂/γ₂, 0):**
```
N₁ = ε₂/γ₂, N₂ = 0
```
- Хищниците са изчезнали
- Жертвите растат експоненциално

#### 4. **Нетривиално (K₁, K₂):**
```
N₁ = K₁ = ε₂/γ₂
N₂ = K₂ = ε₁/γ₁
```
- **ЕДИНСТВЕНАТА ИНТЕРЕСНА ТОЧКА!**
- И двата вида съществуват
- Популациите са в равновесие

---

## 4. **СВОЙСТВА НА СИСТЕМАТА**

### Периодичност:
**Най-важното свойство:** Решенията са **периодични**!

#### Защо?
1. Ако хищниците са много → ядат много жертви → жертвите намаляват
2. Жертвите намаляват → хищниците гладуват → хищниците намаляват
3. Хищниците намаляват → жертвите се възстановяват → жертвите растат
4. Жертвите растат → много храна за хищници → хищниците растат
5. Връщаме се в точка 1 → **ЦИКЪЛ**

### Фазова равнина:
Траекториите в равнината (N₁, N₂) са **затворени криви** около точката (K₁, K₂).

---

## 5. **ПЪРВИ ИНТЕГРАЛ**

### Деривация:
Разделяме уравненията:
```
dN₁/dN₂ = [(ε₁ - γ₁·N₂)·N₁] / [(-ε₂ + γ₂·N₁)·N₂]
```

След разделяне на променливите и интегриране:
```
ε₁·ln(N₂) - γ₁·N₂ + ε₂·ln(N₁) - γ₂·N₁ = C
```
където C се определя от началните условия.

### Значение:
Това е **закон за запазване** - точката (N₁, N₂) се движи по крива с постоянно C.

---

## 6. **СРЕДНИ СТОЙНОСТИ**

### Важно свойство:
Средните стойности за един период са **постоянни**:
```
⟨N₁⟩ = (1/T)·∫₀ᵀ N₁(t)dt = K₁ = ε₂/γ₂
⟨N₂⟩ = (1/T)·∫₀ᵀ N₂(t)dt = K₂ = ε₁/γ₁
```

### Доказателство:
От уравненията:
1. d(ln N₁)/dt = ε₁ - γ₁·N₂
2. Интегрираме за един период T:
   ```
   [ln N₁(t)]₀ᵀ = ε₁·T - γ₁·∫₀ᵀ N₂(t)dt
   ```
   Но лявата страна е 0 (периодичност) → ⟨N₂⟩ = ε₁/γ₁ = K₂

Аналогично за N₂.

---

## 7. **ПЕРИОД НА КОЛЕБАНИЯТА**

### За малки колебания:
Ако популациите са близо до равновесието (K₁, K₂), периодът е:
```
T ≈ 2π/√(ε₁·ε₂)
```

### Свойства:
1. **Не зависи от началните условия!** (само от ε₁ и ε₂)
2. **По-големи ε₁, ε₂ → по-малък период** (по-бързи колебания)
3. Моделът е **изохронен** (като математическото махало)

### Пример:
Ако ε₁ = 0.3, ε₂ = 0.2:
```
T ≈ 2π/√(0.3·0.2) = 2π/√0.06 ≈ 2π/0.245 ≈ 25.7 единици време
```

---

## 8. **ПЛОЩНА СКОРОСТ**

### Дефиниция:
Скоростта, с която радиус-векторът "замета" площ във фазовата равнина:
```
σ = (1/2)·|ρ × v|
```
където ρ = (N₁-K₁, N₂-K₂), v = (dN₁/dt, dN₂/dt)

### Важно свойство:
За системата Лотка-Волтера:
```
σ = (1/2)·[γ₂·N₂·(N₁-K₁)² + γ₁·N₁·(N₂-K₂)²] > 0
```

Това доказва, че точката се движи **винаги в една посока** → периодичност!

---

## 9. **ПРИМЕР 8.1: ЧИСЛЕНО РЕШЕНИЕ**

### Дадено:
```
dN₁/dt = (0.3 - 0.02·N₂)·N₁
dN₂/dt = -(0.2 - 0.01·N₁)·N₂
N₁(0) = 25, N₂(0) = 10
```

### Равновесие:
```
K₁ = ε₂/γ₂ = 0.2/0.01 = 20
K₂ = ε₁/γ₁ = 0.3/0.02 = 15
```

### Резултат:
- Популациите колебаят периодично
- N₁: между ~10 и ~30
- N₂: между ~8 и ~22
- Средни: ⟨N₁⟩ ≈ 20, ⟨N₂⟩ ≈ 15
- Период: T ≈ 25 единици време

---

## 10. **УСЛОЖНЕНИЯ НА МОДЕЛА**

### 1. Конкуренция между жертвите (Пример 8.2):
```
dN₁/dt = (ε₁ - γ₁·N₂ - δ₁·N₁)·N₁
dN₂/dt = (-ε₂ + γ₂·N₁)·N₂
```
- Жертвите се конкурират за храна
- Решенията се "навиват" спираловидно към равновесие
- **Не са периодични!**

### 2. Наследственост (памет):
```
dN₁/dt = (ε₁ - γ₁·N₂)·N₁
dN₂/dt = -[ε₂ - ∫₋∞ᵗ K(t-τ)·N₁(τ)dτ]·N₂(t)
```
- Хищниците помнят колко храна са имали в миналото
- Модел с **интегро-диференциални уравнения**
- По-реалистично, но по-сложно

---

## 11. **ФИЗИЧЕСКА АНАЛОГИЯ**

### Система "пружина-маса":
```
m·d²x/dt² + k·x = 0
```
- Решение: x(t) = A·cos(ωt + φ) (хармонични трептения)
- Енергията се преобразува между кинетична и потенциална

### Система "хищник-жертва":
- "Енергията" се преобразува между популациите
- Когато жертвите са много → "енергия" преминава към хищниците
- Когато хищниците са много → "енергия" преминава обратно

---

## 12. **КЛЮЧОВИ ФОРМУЛИ за ЗАПОМНЯНЕ**

1. **Уравнения:**
   ```
   dN₁/dt = (ε₁ - γ₁·N₂)·N₁
   dN₂/dt = (-ε₂ + γ₂·N₁)·N₂
   ```

2. **Равновесие:**
   ```
   K₁ = ε₂/γ₂, K₂ = ε₁/γ₁
   ```

3. **Период (малки колебания):**
   ```
   T ≈ 2π/√(ε₁·ε₂)
   ```

4. **Средни стойности:**
   ```
   ⟨N₁⟩ = K₁, ⟨N₂⟩ = K₂
   ```

5. **Първи интеграл:**
   ```
   ε₁·ln(N₂) - γ₁·N₂ + ε₂·ln(N₁) - γ₂·N₁ = C
   ```

## 13. **ПРАКТИЧЕСКИ СЪВЕТИ ЗА РЕШАВАНЕ**

### Стъпка 1: Записване на уравненията
1. Определи кое е жертва (положителен ε), кое е хищник (отрицателен ε)
2. Провери знаците: ε₁>0, ε₂>0, γ₁>0, γ₂>0
3. Запиши системата правилно

### Стъпка 2: Намиране на равновесие
1. Реши системата:
   ```
   (ε₁ - γ₁·N₂)·N₁ = 0
   (-ε₂ + γ₂·N₁)·N₂ = 0
   ```
2. Намери всички четири решения
3. Фокусирай се на (K₁, K₂)

### Стъпка 3: Анализ на поведението
1. Провери дали решенията са периодични (обикновеният модел е периодичен)
2. Ако има допълнителен член (като -δ₁·N₁), може да не е периодичен
3. Помни: средните стойности са K₁ и K₂

### Стъпка 4: При специални въпроси
1. **Период:** Използвай T ≈ 2π/√(ε₁·ε₂) за малки колебания
2. **Средни стойности:** Винаги са K₁ и K₂
3. **Площна скорост:** Ако питат, използвай формулата

## 14. **БИОЛОГИЧНА ИНТЕРПРЕТАЦИЯ**

### В реалния свят:
1. **Класически пример:** Рисове и зайци в Канада
   - Популациите на зайците и рисовете колебаят с период 9-10 години
   - Данните от кожарската индустрия потвърждават това

2. **Проблеми на модела:**
   - Твърде прост (няма миграция, ограничени ресурси)
   - В реалността има много фактори
   - Но улавя основния механизъм

3. **Приложения:**
   - Управление на рибни ресурси
   - Контрол на вредители
   - Разбиране на екосистеми

## 15. **СРАВНЕНИЕ С ДРУГИ МОДЕЛИ**

### Лотка-Волтера vs Конкуренция (§7):

| Аспект | Лотка-Волтера | Конкуренция |
|--------|---------------|-------------|
| Взаимодействие | Хищник-жертва | Конкуренция за храна |
| Резултат | Периодични колебания | Един вид изчезва |
| Равновесие | И двата вида оцеляват | Само един вид оцелява |
| Уравнения | dN₁/dt = (ε₁-γ₁N₂)N₁ | dN₁/dt = (ε₁-γ₁F)N₁ |

### Лотка-Волтера vs Логистичен (§5):

| Аспект | Лотка-Волтера | Логистичен |
|--------|---------------|------------|
| Брой видове | 2 | 1 |
| Поведение | Периодично | S-крива |
| Равновесие | Колебания около точка | Устойчива точка |

**Запомни:** Моделът на Лотка-Волтера е първият, който обяснява периодичните колебания в популациите - ключов за разбиране на екосистемите!
